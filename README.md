# Skills

[![skills.sh](https://skills.sh/b/dizk/skills)](https://skills.sh/dizk/skills)

Agent skills som jeg bruker i hverdagen.

## Installering

### skills.sh (alle agenter)

```bash
npx skills@latest add dizk/skills
```

Installeren lar deg velge hvilke skills og hvilke agenter du vil installere for.

### Claude Code-plugin

```
/plugin marketplace add dizk/skills
/plugin install dizk-skills@dizk
```

## Skills

### Writing

- **[enkel-norsk](./skills/writing/enkel-norsk/SKILL.md)**: Skriv, omskriv eller kontroller teknisk tekst på klar norsk bokmål. Passer for issues, PR-er, commit-meldinger, dokumentasjon og feilmeldinger.
